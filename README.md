# Stitch: Tailored Creations

Build a premium mobile-first web application called "Stitch."

Stitch is an AI-powered tailoring marketplace where customers can discover verified tailors, book home measurement appointments, upload fabric images, generate AI outfit previews, place tailoring orders, track order progress, and receive professionally tailored clothing.

The product should feel like a polished startup ready for launch.

## Design Direction

Use the uploaded reference images as the visual inspiration.

Match the overall design language:

• Modern iOS-inspired interface

• Vibrant magenta brand color similar to the references

• Clean white backgrounds

• Large bold typography

• Rounded corners (24px+)

• Large pill-shaped buttons

• Large rounded search bars

• Minimal borders

• Soft shadows

• Premium cards

• Large spacing

• Beautiful fashion photography

• Friendly and modern

• Luxury fashion meets technology

Do NOT copy the reference layouts.

Create original screens while maintaining the same premium aesthetic.
